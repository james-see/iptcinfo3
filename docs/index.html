About

IPTCInfo3 is a Python library for reading and modifying IPTC metadata in JPEG images. The International Press Telecommunications Council (IPTC) defines a format for exchanging meta-information in news content, including photographs. This library lets you embed and extract information like captions, keywords, copyright notices, creator credits, document IDs, and more — no external dependencies required.

Features

🔍 Read & Write Metadata

Extract and modify IPTC metadata — keywords, captions, copyright, creator, document IDs — programmatically.

🐍 Modern Python

Tested on Python 3.10 through 3.15 on every commit via a CI matrix. Drops EOL interpreters.

🌐 Unicode Support

International characters with proper charset handling, including ISO 2022 escape sequences and UTF-8.

🎯 70+ IPTC Fields

Full IIM Application Record coverage: core photo fields plus audio, document ID, and workflow fields.

🤝 Friendly Aliases

creator, credit, and destination work out of the box, matching exiftool and gThumb conventions.

⚡ Zero Dependencies

Pure-Python implementation using only the standard library. No duplicate list entries, safe saves with optional backups.

Quick Start

Reading IPTC Data

from iptcinfo3 import IPTCInfo

# Open an image file
info = IPTCInfo('photo.jpg')

# Read metadata
print(info['caption/abstract'])
print(info['keywords'])
print(info['copyright notice'])
print(info['creator'])   # alias for 'by-line'

Writing IPTC Data

from iptcinfo3 import IPTCInfo

# Open or create IPTC info (force=True for files without IPTC data)
info = IPTCInfo('photo.jpg', force=True)

# Set metadata
info['caption/abstract'] = 'A beautiful sunset over the mountains'
info['keywords'] = ['sunset', 'mountains', 'landscape']
info['copyright notice'] = '© 2026 Your Name'
info['creator'] = 'Your Name'

# Save changes
info.save()

# Or save to a new file
info.save_as('photo_with_metadata.jpg')

Handling Different Charsets

# Specify input and output charsets
info = IPTCInfo('photo.jpg', inp_charset='utf8', out_charset='utf8')

# ISO 2022 escape sequences (including UTF-8 ESC % G)
# are recognised automatically

Supported IPTC Fields

IPTCInfo3 covers the IIM Application Record. Commonly used fields:

Field Name Description Type
object name Title or name of the image String
caption/abstract Description of the image content String
keywords Searchable keywords (duplicates prevented) List
creator2.3.2+ Creator/photographer (alias for by-line) String
by-line Creator/photographer name String
credit line Credit/provider information (IPTC Core 1.1) String
copyright notice Copyright information String
headline Headline of the content String
city City where photo was taken String
country/primary location name Country name String
job id2.4.0+ Job identifier String
unique document id2.4.0+ Globally unique document identifier String
document notes2.4.0+ Workflow / document notes String
destination Destination/transmission reference (alias) String

v2.4.0 also added the audio block (audio type, audio duration, …), object type reference, classify state, catalog sets, and more. See the changelog for the full list.

Advanced Examples

Batch Processing

import os
from iptcinfo3 import IPTCInfo

# Process all JPEG files in a directory
for filename in os.listdir('photos'):
    if filename.lower().endswith('.jpg'):
        info = IPTCInfo(f'photos/{filename}', force=True)
        info['copyright notice'] = '© 2026 Your Name'
        info['keywords'].append('batch-processed')
        info.save()
        print(f"Processed {filename}")

Avoiding Backup Files

# By default, save operations create a backup with ~ suffix
# To disable this, use the overwrite option:
info.save_as('photo.jpg', {'overwrite': True})

Working with Custom Fields

# Custom fields (custom1 through custom20) for non-standard metadata
info['custom1'] = 'Custom metadata value'
info['custom2'] = 'Another custom value'
info.save()
